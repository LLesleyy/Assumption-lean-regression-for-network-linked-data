# Experiments added during revision

- `estimator-comparison`: local two-star and triangle comparison of full OLS,
  full bias-corrected OLS, and downsampled OLS across four sparsity regimes.
- `disjoint-aggregation`: fixed-`K` aggregation over deterministic, disjoint
  regression blocks. It depends on the data seeds produced by the estimator
  comparison.
- `continuous-grdpg`: bootstrap confidence intervals and the joint network
  test under a continuous GRDPG of signature `(2,1)`.
- `real-data-dimension-sensitivity`: school-level spectral exploration and the
  repeated real-data analysis for embedding dimensions 2, 3, and 4.

Exact commands are given in the repository-level `REPRODUCIBILITY.md`.
