# Before making the repository public

- [ ] Choose and add a software license approved by all authors.
- [ ] Confirm the final manuscript citation and add a DOI when available.
- [ ] Confirm that no ICPSR data, processed individual-level data, or local
      `.RData` workspace is staged.
- [ ] Run `Rscript scripts/check_setup.R --tests` from a clean clone.
- [ ] Run at least one smoke experiment from `REPRODUCIBILITY.md`.
- [ ] Confirm that all paths in the README work from the repository root.
- [ ] Inspect `git status` and verify that only intended code, documentation,
      and reported aggregate results are included.
